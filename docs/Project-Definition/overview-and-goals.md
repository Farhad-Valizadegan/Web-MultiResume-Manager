# Overview and Goals

Status: Documented baseline
Reviewed: 2026-10-06
Evidence baseline: local commit 0ca188f (merged project rename), with release history through v1.2.1.

MultiResume Manager lets an account owner maintain multiple professional resumes, publish selected resumes through unique links, control access and downloads, and see aggregate viewing activity. It supports separate administrator and user workspaces.

The problem addressed is keeping different resume versions consistent while sharing them with employers in a controlled, readable format. The product provides per-resume personal information, skills, languages, interests, education, experience, projects and certificates.

Goals are reliable resume editing; clear public presentation and PDF output; owner isolation; controlled file access; and maintainable verification and delivery. Light, Dark and System appearance preferences and collapsible editor sections support usability.

See [scope](scope-and-stakeholders.md) and [success criteria](risks-and-success-criteria.md). This documentation establishes an evidence-based baseline after development; it is not a claim that formal planning preceded every historical change.
