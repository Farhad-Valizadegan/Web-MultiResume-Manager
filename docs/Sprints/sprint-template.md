# Prospective Sprint Template

Status: Template — not an executed sprint
Reviewed: 2026-10-06 (Europe/Berlin)
Source baseline: 0ca188f. This is documentation evidence, not production certification.

## Identity and goal

Sprint identifier, agreed dates/timezone, responsible participants and one observable goal. Leave values unassigned until actually agreed.

## Selected work

For each backlog ID record requirement, outcome, scope/exclusions, dependencies, technical risk and acceptance criteria. Identify manual/PDF/operational checks that cannot be replaced by ordinary unit tests.

## Execution and closure

Record relevant decisions, source/PR links, verification records, actual increment, unfinished items and residual risk. At closure state whether the goal was met, what evidence supports it, and what moves back to the backlog. Distinguish Completed from merely code merged.

## Release relationship

Record any resulting release separately and link its actual tag/notes. A sprint can end without a release. Never fill historical dates or outcomes from assumptions.
